When updating or creating website sections

- Always use the About Page animation style as the baseline for all sections
- Apply scroll-triggered animations using `.text-reveal`, `.image-reveal`, and `.stagger-item` classes
- Use `data-stagger-container` for groups of items that should animate in sequence
- Maintain consistent timing: ease-out curves with 0.5-1.2s duration
- Add hover effects with smooth transitions (0.4-0.6s duration)
- Use `card-hover` class for card components with lift and scale effects
- Ensure all animations trigger when 20-30% of section enters viewport
- Keep mobile animations simpler but maintain the motion design language
- Use Apple-style spacing, typography, and smooth transitions throughout
